# Personal Portfolio Website

## Project Overview

A Personal Portfolio Website developed as part of The Developers Arena Web Development Internship. This project showcases personal information, skills, projects, and contact details through a responsive and user-friendly web interface.

## Features

* About Me section
* Skills showcase
* Projects section
* Contact form
* Responsive design
* Easy navigation

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Kashish26-tech/portfolio-website.git
```

2. Open the project folder.

3. Run `index.html` in any web browser.

## Learning Outcomes

* Semantic HTML structure
* Responsive web design
* Form creation and validation
* Website navigation implementation
* Front-end development fundamentals
