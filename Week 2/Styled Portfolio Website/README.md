# 🌐 Styled Portfolio Website

## 📖 Project Overview

This project is a responsive **Personal Portfolio Website** developed using **HTML5** and **CSS3**. The website showcases my profile, skills, and contact information in a clean, modern, and user-friendly design.

The portfolio demonstrates the use of various CSS concepts such as selectors, Flexbox, hover effects, responsive design, custom fonts, transitions, and transformations.

---

## 🎯 Project Objectives

* Create a visually appealing portfolio website.
* Apply CSS styling to an HTML webpage.
* Use responsive design techniques for mobile devices.
* Implement interactive elements using hover effects and transitions.
* Organize content using modern layout techniques.

---
