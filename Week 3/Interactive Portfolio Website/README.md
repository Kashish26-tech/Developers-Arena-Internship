# 🌐 Interactive Portfolio Website

## 📖 Project Overview

This project is a responsive **Interactive Personal Portfolio Website** developed using **HTML5**, **CSS3**, and **JavaScript**. The website showcases my profile, skills, and contact information while providing an engaging and user-friendly experience through interactive features.

The project demonstrates core JavaScript concepts such as **DOM Manipulation**, **Event Handling**, **Form Validation**, **Local Storage**, and **Dynamic Theme Switching**.

---

## 🎯 Project Objectives

* Create an interactive personal portfolio website.
* Apply JavaScript to make the website dynamic.
* Implement form validation using JavaScript.
* Use DOM manipulation to update webpage content.
* Store user preferences using Local Storage.
* Build reusable JavaScript functions.
* Create a responsive and visually appealing design.
